are the receiving callers. First increment: doctest/CPM and optional nanobench;
architecture/catalog/skill changes define later work without dispatching H2.

shape, boundary, capacity, ordering and acceptance decisions, then split existing
fixtures and wire local manifests before independent T/G/R/Q implementation.

review C++, run combined Debug/Release and supported sanitizer/package gates, and
verify a runtime-only configuration requires no development dependency fetch.
Handoff includes combined SHAs/results, CI/PR evidence and unmet gates. Follow
the catalog for phase reassessment and resource claims.
